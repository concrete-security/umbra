# Support

Umbra is an early-stage open-source project. Community support is best-effort; the project does not promise response or resolution times.

Use a GitHub issue for reproducible bugs and focused feature requests. Include the Umbra version, operating system, relevant non-secret configuration, expected behavior, actual behavior, and the smallest safe reproduction. Use the provided templates where possible.

Before filing, check the README, quick start, module README, specifications, and existing issues. General deployment design questions are welcome, but maintainers cannot operate a contributor's cloud accounts or receive their credentials.

Security vulnerabilities and sensitive incident details must follow `SECURITY.md`, not a public issue. Never post tokens, private keys, session files, full environment files, private logs, or personal data.
